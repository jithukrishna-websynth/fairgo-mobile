# Fair-Go (Customer App)

Flutter app (Android + iOS). State: Riverpod. Navigation: go_router.

## Run
Works with Flutter 3.38+ (Dart 3.10+). The `android/` project was generated by Flutter 3.38.5, so use that or newer.

```
flutter pub get
flutter run            # device/emulator (needs Android SDK or Xcode)
flutter run -d chrome  # quick UI preview
flutter analyze && flutter test
```

## Tests
```
flutter test            # all tests
flutter test --coverage # writes coverage/lcov.info
```
Widget tests cover every screen (`test/features/...`), validators and state (`test/core/`), and two end-to-end flows. `test/helpers/pump_app.dart` starts the real router at any route.

## Structure
`lib/app` (router, theme) · `lib/core` (validators, shared widgets) · `lib/features/{onboarding,authentication,profile}`

## Not yet integrated
- **Auth is demo only** (`DemoAuthRepository`): no SMS is sent; OTP `123456` is accepted. Google/Apple sign-in show a "not configured" message.
- Profile data is not persisted; language choice is not applied to translations.
- **Emergency SOS is a demo.** It does not contact anyone; the screen shows a "DEMO ONLY" notice until `sosIntegrated` in `sos_screen.dart` is set after a real integration.
- Maps: no map SDK or API key yet; the map area is a drawn placeholder. Place search uses demo data (`lib/features/ride/data/demo_places.dart`).
- Home: Bookings/Wallet/Account tabs, service tiles and the "arriving" banner are static until designed.
- Missing assets: official logo, welcome vehicle photo, brand fonts (placeholders used).
